课表日历源码分享包（三端 v3.0）

先看这里
本包是供室友独立搭建、学习和修改的源码，不是双击就能安装的程序。
当前源码包含四端：Android 原生应用与桌面小组件、网页日历、macOS 原生课程岛，以及 Windows 雨滴参考实现。
桌面小组件空间由手机桌面决定，内容较多时需要拉高组件。

v3.0 三端新功能
macOS（SwiftPM 原生课程岛）
1. 纯黑课程岛：刘海处紧凑显示剩余时间与进度，展开后是完整月历 / 今日面板，无刘海屏幕自动切换为悬浮胶囊。
2. 全局快捷键：可在设置中录制快捷键，一键展开今日、打开快速添加或呼出设置。
3. 中文自然语言快速添加：输入“明天下午3点 交实验报告”即可解析日期、时间、类别与标题，保存前可实时预览。
4. 拖拽建待办：把文本或文件从 Finder / 其他应用拖到课程岛，岛会展开并提示“松手创建待办”；松手后进入待办快速添加，预填文本首行或“处理：文件名”，确认后才保存，绝不自动落库。
5. 关联文件：由文件拖拽创建的待办会保存 link，详情弹窗和待办卡片提供“打开文件”按钮；文件不存在时由原生层提示“文件不存在”。

Web / Android 共用能力
1. 待处理分组：今天之前未完成的待办单独成组，可逐条完成、顺延或放弃。
2. 每日回顾：汇总当天完成情况与顺延项，帮助你决定下一步。
3. 归档页：已完成 / 已放弃的历史事项集中查看，支持按类别筛选。
4. 深色模式：跟随系统深色主题，网页与安卓原生界面均适配。

Android 16 专属能力
1. 实时更新课程岛：课程进行中通过 Live Updates / 灵动岛式通知持续展示剩余时间与进度。
2. 大号桌面组件可直接勾选待办，无需打开应用。
3. “下一节课”小组件：桌面常驻显示下一节课的时间、地点与倒计时。
4. 桌面快捷方式：长按应用图标可直达快速添加、今日课表与回顾页。

目录

web：网页日历，可在 Mac、Windows 和 Android 浏览器中使用。
macos-widget：macOS 原生课程岛（SwiftPM 工程、菜单栏控制、黑底无边框面板），源码与 build.sh。
backend/schema.sql：Supabase 数据表和每个用户仅能读写本人数据的规则。
windows-rainmeter：Windows 雨滴日历源码参考，附空白数据，不适用于 macOS。
data：示例课表数据（CSV / JSON / ICS）。
scripts：课表导入、备份导出与上传辅助脚本。
shared：跨端规则测试用例与 JavaScript 测试。
docs/THIRD_PARTY.md：全部第三方依赖、版本、许可证与用途登记。

独立搭建步骤（使用自己的 Supabase 项目）
1. 自己创建 Supabase 项目，保存数据库密码。
2. 在项目的 SQL Editor 执行 backend/schema.sql。保持行级安全（RLS）开启。
3. 从项目 API Keys 获取 publishable key；不要将 secret/service_role key 填入客户端。
4. 修改 web/app.js 顶部的 defaultConfig，填自己的项目 URL 和 publishable key。
5. 将 web 目录里的三个文件部署到自己的静态网站（例如 GitHub Pages）。
6. 在 Supabase Authentication 的 URL Configuration 中，把 Site URL 和允许的回跳地址设为自己的网页完整地址（包括仓库路径）。保留邮箱验证，并通过邮件确认注册。
7. 修改 android/app/src/main/java/com/calendarboard/widget/CalendarApi.java 的 BASE、KEY，填同一个项目的 URL 和 publishable key。
8. 修改同目录 MainActivity.java 的 WEBSITE，填自己的网页日历地址。
9. 两端注册并使用同一个日历账号，即可共享自己的课程、待办和日程。

在 Mac 上编译 Android（SDK 36 / JDK 17）
1. 安装 JDK 17（推荐 Temurin 17）与 Android SDK Platform 36、Build Tools 36.0.0。
2. 使用 Android Studio 打开本包 android 文件夹，等待 Gradle 同步；项目使用 Android Gradle Plugin 8.13.2，建议 Gradle 8.13。
3. 命令行构建：
     cd android
     ./gradlew assembleDebug
   若本包未附带 Wrapper，可直接用本机 Gradle 8.13：
     gradle assembleDebug --no-daemon
4. 输出为 android/app/build/outputs/apk/debug/app-debug.apk；先跑单元测试可用：
     gradle test --no-daemon
5. 测试包使用本机签名，不能直接覆盖原作者签名的 APK。若提示签名冲突，可先导出/确认云端数据，再卸载原应用；或者修改 applicationId 后作为另一个应用安装。
6. 发布长期自用版本时请自己生成并妥善保存签名密钥。

在 Mac 上编译 macOS 课程岛（SwiftPM / build.sh）
1. 要求 macOS 13 或以上，并安装 Xcode Command Line Tools（提供 swift / swiftc）。
2. 在终端执行：
     cd macos-widget
     bash build.sh
   build.sh 使用 SwiftPM（`swift build -c release`）编译 Sources/CalendarBoard，而不是旧的单文件 swiftc 方式；随后复制 web/core.js、ui 资源与 SwiftPM 资源包，生成 macos-widget/CalendarBoard.app，并做本机临时签名。
3. 脚本仅在检测到“只有 Command Line Tools、没有 Xcode.app”时自动回退到 MacOSX26.5.sdk，以规避 SwiftUIMacros 缺失；正常 Xcode 环境无需手动设置 SDKROOT。
4. 首次打开如被系统拦截，可在“系统设置 → 隐私与安全性”中允许打开。课程岛不显示 Dock 图标，通过菜单栏图标操作；快捷键、自动隐藏、同步都可以在菜单与设置中调整。
5. 修改 web/core.js 或 macos-widget/ui 下的资源后重新执行 build.sh，才会把最新代码同步进 macOS 应用包。

Android 权限说明
1. INTERNET / ACCESS_NETWORK_STATE：连接 Supabase 同步课表与账号。
2. POST_NOTIFICATIONS（Android 13+）：课程、待办与每日回顾提醒；首次启动需在系统弹窗中允许。
3. POST_PROMOTED_NOTIFICATIONS：Android 16 实时更新课程岛（Live Updates）使用；系统可能要求用户在通知设置中允许“提升的通知”。
4. RECEIVE_BOOT_COMPLETED：开机后恢复提醒与小组件刷新。
5. USE_EXACT_ALARM：在课程开始、待办截止等时刻精确提醒；若系统限制精确闹钟，请在小米 / HyperOS 的“闹钟与提醒”中放行。
6. 日历、账号与通知内容仅保存在本机与你自己配置的 Supabase 项目；源码不包含作者账号、会话或签名密钥。

小米 HyperOS / MIUI 后台与超级岛设置指引
1. 自启动：设置 → 应用设置 → 应用管理 → 课表日历 → 自启动，允许。
2. 省电策略：同上进入“省电策略”，选择“无限制”，避免课程岛与提醒被后台冻结。
3. 通知权限：设置 → 通知与控制中心 → 课表日历，允许通知；进入“通知类别”，确认“课程提醒”“待办提醒”“每日回顾”均开启。
4. 锁定后台：多任务界面下拉课表日历卡片并点锁形图标，防止一键清理时被杀。
5. 精确提醒：设置 → 应用设置 → 课表日历 → 其他权限 → 闹钟与提醒，允许；并在“电池 → 应用智能省电”中把课表日历设为“不限制”。
6. 超级岛 / 焦点通知（HyperOS 2 及以上）：设置 → 通知与控制中心 → 超级岛（或“焦点通知”），允许课表日历展示实时活动；Android 16 设备还需在“通知 → 提升的通知”中允许本应用。
7. 小组件：长按桌面 → 添加小部件 → 课表日历，可添加“课程月历”“下一节课”“待办清单”三种组件；大号待办组件支持直接勾选。
8. 若提醒仍延迟，请关闭“省电模式 / 超级省电”，并在最近任务中锁定应用后再测试。

Windows 雨滴（仅作参考）
将 windows-rainmeter 文件夹放到 Rainmeter 的 Skins 目录，重命名为 CalendarBoard。
数据已清空。先加载 Calendar.ini 查看空日历，再在 @Resources 中运行 SetupSync.ps1 配置自己的 Supabase URL、publishable key 和账号。
PowerShell 与 Rainmeter 的路径和环境按本机调整。这部分未经 macOS 适配。

隐私与限制
源码不包含原作者的日程、课程数据、账号、会话、同步状态和签名密钥。
如果继续使用当前默认连接配置，请不要往该 Supabase 项目中写入敏感信息；正式自用建议换成自己创建的 Supabase 项目。
不包含 node_modules、Android SDK、JDK、编译产物或历史备份。
源码中的 YOUR_PROJECT、YOUR_USERNAME、YOUR_REPOSITORY、REPLACE_WITH_YOUR_KEY 都必须替换。
本包包含现有实现及说明，尚未在室友的 Mac/安卓设备上逐项验证；小米 HyperOS 的超级岛与后台策略会随系统版本变化，请以本机实际路径为准。
